# 对分易签到助手 (duifene_v2)

自动监控对分易课程签到活动，支持数字码、二维码、定位三种签到类型。检测到签到后延迟/立即自动完成。

## 功能

- **微信链接登录** — 复制微信授权链接即可登录，支持二维码签到
- **账号密码登录** — 直接输入对分易账号密码（不支持二维码签到）
- **数字码签到** — 自动抓取 4 位签到码并提交
- **二维码签到** — 微信登录后自动完成（无需实际扫码）
- **定位签到** — 按配置坐标 + 随机偏移模拟 GPS 签到
- **签到延迟** — 检测到签到后等待 N 秒再签
- **坐标管理** — 独立弹窗，编辑每门课的教室经纬度，点击保存生效
- **零文件写入** — Cookie 和坐标存 Windows 注册表，不产生任何磁盘文件

## 运行

```powershell
pip install requests beautifulsoup4 urllib3 lxml
python duifene_v2.py
```

## 使用步骤

1. 打开软件，选择登录方式
   - **微信登录**：电脑微信打开界面中的授权链接 → 右上角 `...` → 复制链接 → 粘贴到输入框
   - **密码登录**：直接输入对分易账号密码（不支持二维码签到）

2. 登录成功后，下拉框选择要监控的课程

3. 设置签到延迟（可选，默认 0 秒立即签到）

4. 点击「开始监听」，软件每 2 秒轮询一次签到活动

5. 当老师发起签到，软件会自动完成并在日志中显示结果

## 定位签到

定位签到需要每门课配置教室坐标。点击「坐标管理」按钮打开弹窗，在对应的课程行填写经纬度，点击「保存全部」。

坐标获取可按以下顺序：
1. 对分易 API 返回的字段（如有）
2. 坐标管理中用户配置的值
3. 默认 C5 教学楼坐标 `114.39437, 22.70462`

> 默认坐标仅供兜底，不同教室可能超出签到范围导致失败。建议每门课配置实际坐标。

## 签到检测逻辑

每次轮询 MBCount.ashx 获取签到列表，筛选待签到：

- 跳过已签到（CheckInStatus / CheckInDate / StudentID 任一有值）
- 跳过已出勤（StatusID=1 或 StatusName=出勤）
- 跳过不可申请（CanApply≠1）
- 跳过已过期（当前时间超过 ApplyLimitDate）
- 跳过超过 30 分钟的旧签到

同一会话内绝不重复尝试同一条签到。检测到后立即执行或按延迟等待。

## 数据存储

所有数据存入 Windows 注册表 `HKEY_CURRENT_USER\Software\duifene`：

- `cookie` — 登录会话 Cookie，重启软件自动恢复
- `locations` — 课程坐标配置 JSON

首次登录自动创建，退出不会丢失。

## 注意事项

- 二维码签到必须使用**微信链接登录**，密码登录不支持
- 定位签到时自动切换手机 UA，签到完成后恢复
- 不要频繁启停监控，可能触发服务器限流
- Cookie 过期后需重新登录
- 每门课首次定位签到前，建议先在坐标管理中填写实际教室经纬度
