# 对分易签到助手 (duifene_v2)

自动监控对分易课程签到活动，支持数字码、二维码、定位三种签到类型。

## 功能

- **微信链接登录** — 复制微信授权链接即可登录，支持二维码签到
- **账号密码登录** — 直接输入对分易账号密码
- **数字码签到** — 自动抓取 4 位签到码并提交
- **二维码签到** — 微信登录后自动完成
- **定位签到** — 用预设坐标 + 随机偏移模拟 GPS 定位
- **签到延迟** — 界面可设检测到签到后等待 N 秒再签
- **过期过滤** — 自动跳过 30 分钟前的历史签到

## 安装

```powershell
pip install requests beautifulsoup4 urllib3 lxml
```

## 运行

```powershell
python duifene_v2.py
```

## 使用步骤

1. 打开软件，选择登录方式
   - **微信登录**：电脑微信打开界面中的授权链接 → 右上角 `...` → 复制链接 → 粘贴到输入框
   - **密码登录**：直接输入对分易账号密码

2. 登录成功后，下拉框选择要监控的课程

3. 设置签到延迟（可选，默认 0 秒立即签到）

4. 点击「开始监听」，软件每 2 秒轮询一次签到活动

5. 当老师发起签到，软件会自动完成并在日志中显示结果

## 定位签到配置

定位签到需要教室的经纬度坐标。在项目目录创建 `locations.json`：

```json
{
    "课程名称": {
        "lng": "经度",
        "lat": "纬度",
        "note": "教室位置"
    }
}
```

未配置的课程默认使用 C5 教学楼坐标（深圳技术大学）。

## 文件说明

| 文件 | 用途 |
|---|---|
| `duifene_v2.py` | 主程序 |
| `duifenyi.ini` | 登录 cookie 缓存（自动生成） |
| `locations.json` | 定位签到坐标配置 |

## 注意事项

- 二维码签到必须使用**微信链接登录**，密码登录不支持
- 不要频繁启停监控，可能触发服务器限流
- Cookie 过期后需重新登录
